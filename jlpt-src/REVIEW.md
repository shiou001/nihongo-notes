# JLPT 題目獨立審查

這份是給**審查者**的說明。審查者沒有參與出題，只負責逐題檢查。

## 你的任務

你是一位熟悉 JLPT 的日語老師，要檢查一批**原創**的 JLPT 練習題（JSON 檔）。這些題目會給**初學者**使用，對方沒有能力自己發現錯誤，所以要嚴格。

先讀：
- `jlpt-src/README.md`：題目格式與標記方式
- `js/jlpt-core.js` 裡的 `TYPES`：題型與作答說明

再讀要審查的批次檔。有 `gen` 的題目，選項由程式產生；請先執行 `node tools/build-jlpt.mjs`，再到 `data/jlpt.js` 找建置後的選項。如果批次還沒審查（`reviewed: null`），題目不會出現在 `data/jlpt.js`。這時可以暫時用下面的指令取得產生後的選項：
`node -e "import('./tools/build-jlpt.mjs').then(async m=>{/* 用 genChoices 印出 */})"`
或者直接根據規則判斷。

## 逐題檢查

1. **答案唯一**：正確答案只有一個，其他選項都不能說得通。注意：
   - 助詞的替換（へ／に、まで／へ 常常都對）
   - 排序題有沒有第二種合法順序
   - 換句話說題的意思是不是真的相同
2. **日文自然**：題目和選項是母語者會說、會寫的日文。
3. **程度**：
   - 單字、文法在 N5 範圍內（N4 批次就是 N4 範圍）。
   - 文字・語彙科裡沒有標振假名的漢字，必須是該級漢字。這條只管「題目」和「正確答案」；表記題的干擾選項可以用超出級數的形近字，因為正式考試也這樣出。
4. **詳解正確**：中文說明要正確，並清楚說明為什麼其他選項錯。
5. **格式**：
   - 詞語之間有全形空格。
   - 文字・語彙科沒有振假名；文法・讀解科每個漢字都有 `{漢字|よみ}`。
   - 底線標在正確的位置。
   - 排序題 ★ 的位置對應到正確答案。
6. **聽解**（如果有）：
   - 腳本和選項、插圖描述一致。
   - 旁白的提問在對話前、後各一次。
   - 答案能從對話裡聽出來。
7. **原創**：不是照抄或改寫官方考古題、市售題本。

## 回報格式

每題一行：

```
<id> | OK
<id> | 問題：… | 建議：…
```

最後一行寫出：`總計：N 題，OK X 題，需修正 Y 題`。只回報，不要修改檔案。
